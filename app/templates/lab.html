All scenarios run against this application's own security controls using synthetic data. No external targets are contacted.

Scenario 1 — Unauthorised Access

Tests whether an operator-role user can perform administrator actions. Exercises the actual authorisation check.

Scenario 2 — Message Tampering

Creates a message with a valid HMAC tag, modifies the body, and checks whether HMAC verification detects the change.

Scenario 3 — Message Replay

Inserts a message, then verifies that the same UUID cannot be reused, preventing replay or duplicate submission.

Scenario 4 — Rate Limiting

Verifies that rate-limiting configuration is active on login and message endpoints.

Scenario 5 — SQL Injection

Sends a classic SQL injection payload through the ORM's parameterised query and confirms it is treated as literal data.
